# Project photos

Drop each project's photos into its folder here:

  src/assets/projects/the-kitchen/
  src/assets/projects/pinnova/
  src/assets/projects/utsav/

Any .jpg / .jpeg / .png / .webp / .avif file you add is picked up
automatically and shown in a "Photos" gallery on that project's page —
no code changes needed. Files are shown in filename order (use names like
01.jpg, 02.jpg to control the order).

Tip: keep images reasonably sized for web (JPG/WebP, ~1600px on the long
edge) so pages stay fast.
