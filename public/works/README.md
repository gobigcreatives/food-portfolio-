# Works media

Put your portfolio images and videos here, then reference them in
`src/data/works.js` on the matching item.

- Image:  add `image: "/works/your-file.jpg"`
- Video:  add `video: "/works/your-file.mp4"` (autoplays muted + looped)
          optionally `poster: "/works/your-file.jpg"` for the first frame

Any item WITHOUT an `image`/`video` shows a neutral placeholder.

Recommended:
- Images: JPG/WebP, ~1600px on the long edge, < 400 KB each
- Video:  MP4 (H.264) or WebM, muted, 5–15 s loops, < 5 MB each
